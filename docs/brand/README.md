# AgriOpportunity brand

**The mark:** a young plant whose stem grows into an upward arrow, under a rising sun. It stands for growth, moving up, and opportunity in agriculture. It is an original design for this project.

| File | Use |
|---|---|
| `mark.svg`, `mark-1024.png` | App icon style mark (green rounded square) |
| `mark-green-on-white.svg` | Mark without the background, for light backgrounds |
| `logo-horizontal.svg` / `.png` | Mark + "AgriOpportunity" wordmark + tagline (light backgrounds) |
| `logo-horizontal-white.svg` / `.png` | Same on dark green (slides, video title) |

App copies live in `app/assets/` (`icon.png`, `android-icon-*.png`, `splash-icon.png`, `favicon.png`, `logo-mark.png`).

**Colours:** green #1F7A3E · dark green #145A2C · soft green #E6F4EA · sun amber #F2A93B · text #1B2A1F
**Wordmark:** "Agri" in green, "Opportunity" in dark text, bold sans-serif (Inter, Roboto or DejaVu Sans).
**Do:** keep space around the mark equal to the sun's width. **Don't:** stretch it, recolour the leaves, or put it on busy photos.
